# Golden Transcripts

Fixed-seed 100-beat session transcripts for CI drift detection.

## Sessions

1. `01_scarcity_medium.md` — Scarcity argument, medium tension
2. `02_betrayal_high_crack.md` — Betrayal/high-tension CRACK session
3. `03_reconciliation_low.md` — Low-tension reconciliation session
4. `04_cross_pair_eavesdrop.md` — Cross-pair eavesdropping session
5. `05_audience_veil_heavy.md` — Audience/Veil-heavy session

## Usage

Golden transcripts are generated by the theater harness with deterministic
model stubs. They serve as drift-detection artifacts, not strict byte-for-byte
approvals. When the model stub changes, regenerate transcripts and review
manually.

## Regeneration

```bash
docker exec god-runtime python -m banter.theater_harness --generate-golden
```
