# Avatar Assets

`brunette.glb` and `mpfb.glb` are copied from `met4citizen/TalkingHead` for the local avatar lab.
The upstream TalkingHead README states that the MPFB example avatar was created
with Blender and the MPFB extension and is licensed under CC0.
The upstream README states that `brunette.glb` was created at Ready Player Me
and is free to developers for non-commercial use under CC BY-NC 4.0.

Source: https://github.com/met4citizen/TalkingHead
